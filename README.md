# Pang-Wei Huang — Personal Site

A responsive, bilingual personal portfolio built as a static site for GitHub Pages.

## Publish at `https://brianhuangntucsie.github.io/personal-webpage/`

1. In **Settings → General → Danger Zone**, change this repository from private to public so its Pages site can be viewed publicly.
2. In **Settings → Pages**, choose **GitHub Actions** as the build and deployment source.
3. Enable GitHub Actions if prompted. The included workflow publishes the site after each push to `main`.

The résumé download is served from `resume/resume_2027_taiwan.pdf`. Update that file and its link in `index.html` when you replace the résumé.
