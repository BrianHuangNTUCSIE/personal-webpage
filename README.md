# Pang-Wei Huang — Personal Site

A responsive, bilingual personal portfolio built as a static site for GitHub Pages.

## Publish at `https://brianhuangntucsie.github.io`

1. Create a GitHub repository named `BrianHuangNTUCSIE.github.io`.
2. Put these files at the repository root and push the `main` branch.
3. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source.
4. The included workflow publishes the site after each push to `main`.

The résumé download is served from `resume/resume_2027_taiwan.pdf`. Update that file and its link in `index.html` when you replace the résumé.
